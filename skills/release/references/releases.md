# 已发布内容

新的记录写在最上面。正式版 tag 是 `vX.Y.Z`。Nightly 是预发布，不取代 latest。

## v0.0.3

2026-10-05。正式版，取代 `v0.0.2` 成为 latest。

- 打开交互界面后立刻能看到扫描进度，空列表时可以按 `q` 退出，不用干等黑屏。
- 按键更跟手。扫描大目录、以及里面有大量未跟踪文件的 worktree 更快，不会把 `node_modules` 一类目录逐文件走一遍。
- `--json` 会带上这次扫描花了多少毫秒。
- 修复了若干已知问题。

## v0.0.2

2026-10-04。正式版，取代 `v0.0.1` 成为 latest。

- 可以用 `wtrm plan`、`delete`、`clean` 的 JSON 协议查看、预演和执行删除。默认 dry-run，加上 `--yes` 才改磁盘。每条 worktree 有稳定 id。
- 交互删除要按 `y` 或输入 `delete`。底部会列出每条成功、被阻止或失败的原因。Enter 不会删除。
- 删除 worktree 时可以选择保留分支、只删除本地分支，或连 GitHub 远程分支一起删除。别的检出还在使用的分支会留下。
- 状态用 `[main]`、`[dirty]`、`[locked]`、`[merged]` 直接标出来，窄终端也会保留这些标记。
- 修复了若干已知问题。

## v0.0.1

2026-09-23。

- 扫描这台机器上的 git worktree，按最后活跃程度列出仓库、分支、所在文件夹和路径。
- 在终端里多选删除。删除走 `git worktree remove`，主检出不能删除。
- 可以筛出已合并、不活跃，或创建很久且最近没有动作的 worktree。
- 可以只清理 worktree 里的依赖目录，worktree 本身还在。
- GitHub Release 提供 macOS、Linux 和 Windows 二进制包。
